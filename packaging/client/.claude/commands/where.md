description: Where a build has got to, and what it has cost
argument-hint: "[project-id]"
---

Run `bin/site status $ARGUMENTS` (or `bin/site projects` if no id was given).

Summarise for the user in three lines: what stage it is at, what it has cost so
far, and what happens next. If a gate is open, say what it is asking and offer to
walk them through it with `/gate`.

No JSON, no log dumps.
